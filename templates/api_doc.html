🚀 Quick Start

API 基础地址: http://localhost:7860

所有 API 调用都需要先获取 event_id，然后通过 event_id 获取结果。

API Base URL: http://localhost:7860

All API calls require obtaining an event_id first, then use it to get results.

👁️ 预览样式

👁️ Preview Style

POST /gradio_api/call/preview

生成歌词样式预览图，用于在生成视频前预览效果。

Generate a lyrics style preview image to preview before generating video.

请求参数

Request Parameters

参数 Parameter 类型 Type 默认值 Default 说明 Description
font_family string "Microsoft YaHei" 字体名称 Font name
font_file string/null null 自定义字体文件路径 Custom font file path
font_size integer 36 字体大小 Font size
font_color string "#FFFFFF" 字体颜色 Font color
outline_color string "#000000" 描边颜色 Outline color
outline_width number 3 描边宽度 Outline width
bold boolean true 是否加粗 Bold text
pos_x string "中" 水平位置: 左/中/右 Horizontal position: 左/中/右
pos_y string "下" 垂直位置: 上/中/下 Vertical position: 上/中/下
margin_h integer 10 水平边距 Horizontal margin
margin_v integer 50 垂直边距 Vertical margin
bg_color string "#000000" 背景颜色 Background color
resolution string "1920x1080" 分辨率 Resolution

调用示例

Example

# 1. 调用接口
curl -X POST http://localhost:7860/gradio_api/call/preview \
  -H "Content-Type: application/json" \
  -d '{"data": ["Microsoft YaHei", null, 36, "#FFFFFF", "#000000", 3, true, "中", "下", 10, 50, "#000000", "1920x1080"]}'

# 返回: {"event_id": "xxx"}

# 2. 获取结果
curl -N http://localhost:7860/gradio_api/call/preview/{event_id}

🎬 生成视频

🎬 Generate Video

POST /gradio_api/call/generate

生成带歌词字幕的视频。

Generate video with lyrics subtitles.

请求参数

Request Parameters

参数 Parameter 类型 Type 必填 Required 说明 Description
audio FileData ✅ 音频文件 Audio file
lrc FileData ✅ LRC 歌词文件 LRC lyrics file
其他参数同"预览样式"接口 Other parameters same as Preview Style API

调用示例

Example

curl -X POST http://localhost:7860/gradio_api/call/generate \
  -H "Content-Type: application/json" \
  -d '{
    "data": [
      {"path": "/path/to/audio.mp3", "meta": {"_type": "gradio.FileData"}},
      {"path": "/path/to/lyrics.lrc", "meta": {"_type": "gradio.FileData"}},
      "Microsoft YaHei", null, 36, "#FFFFFF", "#000000", 3, true,
      "中", "下", 10, 50, 500, 500, "#000000", "1920x1080"
    ]
  }'

🐍 Python 示例

🐍 Python Example

import requests

# 1. 预览样式
response = requests.post(
    "http://localhost:7860/gradio_api/call/preview",
    json={
        "data": [
            "Microsoft YaHei",  # font_family
            None,               # font_file
            36,                 # font_size
            "#FFFFFF",          # font_color
            "#000000",          # outline_color
            3,                  # outline_width
            True,               # bold
            "中",               # pos_x
            "下",               # pos_y
            10,                 # margin_h
            50,                 # margin_v
            "#000000",          # bg_color
            "1920x1080"         # resolution
        ]
    }
)
event_id = response.json()["event_id"]
print(f"Event ID: {event_id}")

# 2. 获取结果
result = requests.get(
    f"http://localhost:7860/gradio_api/call/preview/{event_id}",
    stream=True
)
for line in result.iter_lines():
    if line:
        print(line.decode())

📤 响应格式

📤 Response Format

API 使用 SSE (Server-Sent Events) 流式响应格式：

API uses SSE (Server-Sent Events) streaming response format:

event: complete
data: [{"path": "/tmp/gradio/xxx/image.webp", "url": "http://localhost:7860/gradio_api/file=..."}]

注意：图片和视频文件通过 url 字段获取，可直接在浏览器中访问。

Note: Image and video files are obtained via the url field and can be accessed directly in the browser.

⚠️ 错误处理

⚠️ Error Handling

常见错误响应：

  • 404 - API 未启用或端点不存在
  • 422 - 参数验证失败
  • 500 - 服务器内部错误

Common error responses:

  • 404 - API not enabled or endpoint not found
  • 422 - Parameter validation failed
  • 500 - Internal server error
